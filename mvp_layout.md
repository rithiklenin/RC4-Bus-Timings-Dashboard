# RC4 Smart Display Network: Suggested MVP Layout

| Screen Area | Content | Behaviour |
|---|---|---|
| **Centre — largest area** | CSC posters, RC4 events, sign-up deadlines | **Rotates/cycles** |
| **Side panel — always visible** | Live NUS shuttle + selected public bus timings | **Persistent + auto-refreshing** |
| **Secondary area** | Dining hall menu / selected RC4 announcements | **Rotates/cycles** |
| **Not prioritised initially** | Weather, generic campus updates, low-demand bus stops | Exclude from MVP |

**Core design principle:** **rotating central CSC publicity + persistent time-sensitive live information**, with the whole display understandable within a few seconds.
